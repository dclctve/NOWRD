# NOWRD CMS v20 — Visual refinement

## Changes
- Mature Classic and Glassmorphism modes remain switchable from the display panel.
- Added six palettes: Classic, Glass, Ocean Blue, Purple Dream, Forest Green, Sunset.
- Added motion controls: Off, Subtle, Smooth (default), Playful.
- Refined floating dock, hover/press states, glass borders, layered shadows, panel entrance animation and surface transitions.
- Improved dark glass surfaces and responsive reduced-motion behavior.
- Preferences remain browser-local, preserving the existing database schema and shared-hosting setup.

## Verify after upload
1. Open admin and use the floating `Tampilan` control (or launcher).
2. Switch Classic / Glassmorphism and verify navigation remains usable.
3. Try all palettes, light/dark/system, dock size/position, blur and transparency.
4. Try each motion setting and confirm Off disables animation.
5. Test on mobile and desktop; `backdrop-filter` support varies by browser.
6. Clear cache in Maintenance or hard-refresh if old assets remain cached.

The ZIP passed static syntax and archive checks. Live browser, database and hosting tests have not been performed in this build environment.
